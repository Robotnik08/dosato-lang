# Dosato-lang

Dosato-lang is a work-in-progress Rust implementation of the Dosato programming language. <br>

The original (cdosato) is a C implementation I made [here](https://github.com/Robotnik08/cdosato).

## Motivation

The original Dosato interpreter was written in C, which made it difficult to maintain and extend. <br>

It proved the language's concepts, and it's more than capable of running Dosato programs, but I hit a bit of a roadblock when trying to add Asynchronous programming support. <br>

Rust, with its strong type system and memory safety guarantees, seemed like a better fit for the language's goals. <br>
